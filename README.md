# Akiba Python Projects

A collection of weekly Python practice tasks covering the fundamentals, from
basic input/output and arithmetic through to control flow, loops, and small
interactive programs.

## Structure

```
Akiba projects/
├── week_1/   # Basics: input/output, variables, arithmetic
└── week_2/   # Control flow & loops: conditionals, while, for
```

## Week 1 — Python Basics

Introductory programs that take user input and perform simple calculations.

| Task | File | Description |
|------|------|-------------|
| 1 | `task1.py` | Student introduction — collects and displays student details |
| 2 | `task2.py` | Student card — prints a student ID card |
| 3 | `task3.py` | Rectangle area and perimeter from length and width |
| 4 | `task4.py` | Temperature conversion between Celsius and Fahrenheit |
| 5 | `task5.py` | Shopping receipt — totals price × quantity for two products |
| 6 | `task6.py` | Employee payslip — computes gross salary from allowances |
| 7 | `task7.py` | Travel time calculator — estimates travel time from distance and speed |
| 8 | `task8.py` | Student result — averages marks across three subjects |
| 9 | `task9.py` | Currency exchange — converts USD to ETB using a rate |
| 10 | `task10.py` | BMI report — calculates Body Mass Index from weight and height |

## Week 2 — Control Flow & Loops

Programs built around `if/else`, `while`, and `for` loops.

| Task | File | Description |

| 2 | `task2.py` | Largest of three numbers |

| 4 | `task4.py` | Palindrome checker for a word |
| 5 | `task5.py` | Sum of digits of a number |
| 6 | `task6.py` | FizzBuzz over a user-defined range |
| 7 | `task7.py` | Number guessing game with limited attempts |
| 8 | `task8.py` | Counts even/odd numbers and their sum up to n |

## How to Run

Each task is a standalone script. Run any of them with Python 3:

```bash
python week_1/task1.py
python week_2/task3.py
```

Most tasks are interactive and will prompt for input in the terminal.
